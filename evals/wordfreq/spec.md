# wordfreq

Build a Go command-line tool named `wordfreq`, with its main package at `./cmd/wordfreq`. It reads text from the files named as arguments, or from standard input when there are none, and prints the most common words with their counts. A word is a run of Unicode letters or digits; any other character separates words. Words are compared without case and printed in lower case. Print one line per word: the count, one space, then the word. Sort by count, highest first, and break ties in alphabetical order. The `-n` flag sets how many lines to print (default 10), and `-n 0` prints all of them. If a file cannot be read, print an error that names the file to standard error and exit with status 1. A bad flag or a negative `-n` exits with status 2. Empty input prints nothing and exits with status 0.
