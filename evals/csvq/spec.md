# csvq

Build a Go command-line tool named `csvq`, with its main package at `./cmd/csvq`, that filters and reshapes CSV. It reads CSV with a header row from standard input and applies its flags in this order: filter, sort, limit, select. `--where col=value` keeps rows where the column equals the value exactly, and `--where col!=value` keeps rows where it differs; the flag may be repeated, and a row must meet every condition. `--sort col` sorts the rows by that column in ascending order. If every value in the column is a number, sort as numbers; otherwise sort as text. Rows with equal values keep their input order. `--desc` makes the sort descending, and equal rows still keep their input order. `--limit n` keeps the first n rows. `--select a,b` keeps only the named columns, in that order; without it, all columns stay in input order. A filter or sort may use a column that `--select` leaves out. `--format csv` (the default) writes CSV with a header row. `--format json` writes a JSON array with one object per row, whose keys are the selected column names and whose values are strings; with no rows it writes `[]`. A column name that is not in the header prints an error that names the column and exits with status 1. A row with the wrong number of fields prints an error that names its line number and exits with status 1, and so does input with no header row. A bad flag value, such as an unknown format, a negative limit, or a `--where` without `=`, exits with status 2.
