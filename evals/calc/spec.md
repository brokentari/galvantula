# calc

Build a Go command-line tool named `calc`, with its main package at `./cmd/calc`. It evaluates arithmetic expressions. Each argument is one expression; with no arguments it reads one expression from each line of standard input and skips empty lines. It prints one result per expression, one per line. An expression has decimal numbers (such as `3`, `2.5` and `.5`), the operators `+`, `-`, `*`, `/`, `%` and `^`, and parentheses. Spaces between tokens do not matter. `^` raises to a power, groups from the right, and binds tighter than `*`, `/` and `%`, which bind tighter than `+` and `-`; operators of the same level group from the left. `-` and `+` also work as signs, as in `-3` and `2*-3`; a sign binds tighter than `*` but less tightly than `^`, so `-2^2` is `-4`. `%` is the remainder of a division, with the sign of the left side, as in Go's `math.Mod`. Results are floating point. Print a whole number with no decimal point (`4`, not `4.0`), and any other number with the shortest form that reads back to the same value (`0.1`, `2.5`). Print `-0` as `0`. If an expression has a syntax error, print a message to standard error that starts with the expression and the zero-based position of the first bad character, and go on with the next expression. Division or remainder by zero also prints an error and goes on. After the last expression, exit with status 1 if any expression had an error, and 0 otherwise. Results of the expressions that worked are still printed. A bad flag or an unknown option exits with status 2.
