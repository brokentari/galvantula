# dedupe

Build a Go command-line tool named `dedupe`, with its main package at `./cmd/dedupe`. It reads lines from the files named as arguments, or from standard input when there are none, and prints the lines without repeats. Unlike `uniq`, it finds repeats anywhere in the input, not only next to each other. By default it prints each distinct line once, at the place where it first appeared. The `-i` flag compares lines without regard to case; the printed line is the first one seen, in its original case. The `-c` flag puts the number of times each line appeared, then a tab, before it. The `-d` flag prints only lines that appeared more than once, and the `-u` flag prints only lines that appeared exactly once; giving both is a usage error. Lines end at a newline. A last line with no newline counts as a line and is printed with a newline. A line with only spaces is a line, and so is an empty one. Lines from several files are treated as one list, in the order of the arguments. If a file cannot be read, print an error that names the file to standard error and exit with status 1; print nothing to standard output. A bad flag or the flags `-d` and `-u` together exit with status 2. Empty input prints nothing and exits with status 0.
