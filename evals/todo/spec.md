# todo

Build a Go command-line tool named `todo`, with its main package at `./cmd/todo`, that keeps a to-do list in a JSON file. The `--file` flag, given before the subcommand, names the file; it defaults to `todo.json` in the current directory, and a missing file means an empty list. `add <text...>` joins its arguments with single spaces, adds an open item, and prints `added <id>`. Ids start at 1, go up by one, and are never reused, even after an item is removed. `list` prints the open items in id order, one per line as `<id> <text>`. `list --all` prints every item as `<id> [ ] <text>` when open or `<id> [x] <text>` when done. `done <id>` marks an item done and prints `done <id>`; marking a done item again is not an error. `rm <id>` removes an item and prints `removed <id>`. An id that does not exist prints an error to standard error and exits with status 1. An unknown subcommand, a missing or non-numeric id, or empty text exits with status 2. Save the file by writing a temporary file in the same directory and renaming it, so a crash never leaves a half-written list.
